# Tank Monitoring Dashboard – Syncfusion Essential JS 2 (Standalone JavaScript)

This sample demonstrates how to build a web-based business application using Syncfusion UI components, including DataGrid, Forms, DropDown Lists, Charts, and Dialogs.

## Getting Started

Follow these steps to run the application:

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Run the application**

   ```bash
   npm run dev
   ```

3. **Open the application in your browser**

   The application will typically be available at [http://localhost:3000](http://localhost:3000/) or at the port shown in your terminal.
